# Harbourmaster Oko (Halcyon)

*A crane-armed fortress barge.* Port Authority. Fortress: armoured but for its weak points, which open after it commits.

- **Now:** sweep (scissor beams), gate (a closing wall with a gap), shells; signature **CRANE SWING** (a wrecking ball on a chain swings a pendulum under the barge, shedding shrapnel at the ends). Filler: lasers, walls, fans, rings. Calls wardens.
- **Personality (1):** no one aboard. A port official enforcing tariffs would give it a voice (fines, inspections, a horn before every move).
- **Dance (2):** the crane is a good learnable pendulum; sweep and gate are clear. The phases only add moves.
- **Model (2), animation (1):** a barge with cranes; one idle loop (`cranes_idle`). No poses: the crane doesn't visibly swing the ball, the view draws it.
- **Music (1):** the shared boss track.
