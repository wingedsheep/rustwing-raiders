# The Collector

*Secrets.* Event: `signal` (STRANGE SIGNAL). Overview: [the NPCs](README.md).

Never seen; pays by return for the coordinates of things older than people. Pays 15 more each time you sell to him (`run.collector`), and always asks you to keep an ear open.
- In the lore, "he" is the Ledger Clan, rebuilding the true ledger from beacon readings ([the Waking](../lore/the-waking.md#the-truth-for-us-not-the-player)).
